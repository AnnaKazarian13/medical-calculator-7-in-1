# Medical Calculator 7-in-1

Desktop application for calculating common clinical screening indices.

**Stack:** Python 3.10+, CustomTkinter

## Calculators

1. BMI (WHO categories)
2. Smoking index (pack-years)
3. Daily fluid requirement
4. BMR (Mifflin–St Jeor)
5. Waist circumference (IDF thresholds)
6. HOMA-IR
7. Glasgow Coma Scale (GCS)

## Features

- Sidebar navigation between tools
- Light / dark theme
- CustomTkinter UI

## Install and run

```bash
git clone https://github.com/AnnaKazarian13/medical-calculator-7-in-1.git
cd medical-calculator-7-in-1
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
